UI compartida: primitives y patrones canónicos para módulos nuevos.

Wrappers semánticos: `admin-*` y composiciones de dominio sobre la base compartida.

Feedback: carga, vacío, error y estados de sistema fuera de alertas operativas.

Legacy / derivados: aliases y variantes heredadas que siguen activas por compatibilidad.
