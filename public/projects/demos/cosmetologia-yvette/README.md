# Centro de Estética Yvette — Demo Estática

Esta carpeta `cosmetologia-yvette` contiene una versión estática, moderna y autónoma (sin backend, bases de datos ni dependencias de servidor) diseñada para demostraciones rápidas y visualización de la propuesta.

## Contenido
- **`index.html`**: Landing page responsive real con secciones de servicios, información del centro (desde 2005 en Cercado de Lima), equipo de especialistas (Yvette, Elizabeth, Lourdes) y accesos directos.
- **`admin.html`**: Panel administrativo y de colaboradoras mobile-first, con tarjetas apiladas (sin tablas), cambio de pestañas interactivo (Dashboard, Citas, Servicios, Inventario) y métricas simuladas.

## Cómo visualizar
Simplemente abre el archivo `index.html` en cualquier navegador web o utiliza una extensión de servidor local como *Live Server* en VS Code.
